# Worker B merchant support

Prepared on isolated branch `codex/tier-one-roasters-b`, based on `c70ae60`. The assigned merchants are Prodigal, Round Hill, S&W Craft Roasting, September, SEY, Shoebox, Substance, Subtext, Sweven and Taith. This work uses public merchant GET requests and a disposable local test database. It does not install, migrate, activate or write to production.

The associated live reports contain the exact product and variant identities, paired price/currency, stock, explicit bag weight, description/image presence, discovery pages and request receipts. Failed or incomplete reads cannot authorize absence reconciliation. Native product identity must match the requested handle, IDs must be unambiguous, and duplicate catalogue or SKU identities cannot establish complete inventory.

Prodigal's roasted-coffee and recent sold-out collections contain 22 verified coffees. One obsolete iced-coffee route serves a primary soft 404. Grinder seasoning and subscriptions are excluded. Ambiguous sampler weights remain unset.

Round Hill's coffee collection contains 13 verified coffees and 162 native variants, with exact GBP offers and explicit size labels.

S&W uses Square's public storefront API, scoped to the site/owner identities in the merchant bootstrap. Its current, blend, archived and Roaster's Select categories contain 153 coffees and 171 coffee SKUs. Tips and the cascara product are excluded by exact identity. A mixed coffee/tea sample exposes only its 19 verified coffee SKUs and does not authorize retirement of the omitted tea SKU. Explicit bag statements provide sample weights; shipping mass and brewing instructions do not. Three products lacking an unambiguous net-size statement retain unset weight.

September's public homepage selects the US market. Its `/en-us/` coffee, garage-sale and archive collections contain 386 verified coffees with 408 exact USD variants. Primary product details augment empty native descriptions only when product ID and heading agree. Explicit bag labels and native size paragraphs supply weights. The sole Style option may select Filter/Espresso without changing stated size; the sole Roasted option may select roast dates. A Size option with multiple bags cannot receive a general fixed weight.

September's Canadian root cache also retains La Muralla #2, product ID `7484652683362`. Its raw numeric cache price does not establish a current paired offer. The primary route redirects to the shop homepage, its native description is empty, and the US native endpoint returns 404. This is an unresolved market/merchant source limitation; it is not proof of global product removal. The September profile sets `inventory_authorizes_global_absence: false`, and the normal crawler checks this before global reconciliation. Canonical `/products/` identity is retained when visiting `/en-us/products/` so existing product IDs and slugs are adopted rather than recreated. Forty-three archived variants lack a safe explicit size and retain unset weight.
